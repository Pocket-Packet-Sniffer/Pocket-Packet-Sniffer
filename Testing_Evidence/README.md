# Testing_Evidence

This folder contains the original PNG screenshots from the Pocket Packet Sniffer testing rerun and a consolidated report.

## Folders
- `01_Full_Test_Suite` — complete Python test suite
- `02_Component_Testing` — capture, analysis, storage, presentation, API and CLI
- `03_System_Testing` — integration test
- `04_Sanity_Testing` — storage, API and frontend typecheck evidence
- `05_White_Box_Testing` — coverage run and exact coverage percentages
- `06_Black_Box_Testing` — browser end-to-end tests
- `07_Code_Quality` — frontend build and Ruff lint evidence
- `Final_Testing_Report` — consolidated results and limitations

The screenshots are original user-supplied captures, not recreated terminal output.
See `Final_Testing_Report/TESTING_REPORT.md` for results and caveats.
